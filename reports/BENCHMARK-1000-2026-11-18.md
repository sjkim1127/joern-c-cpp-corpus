# Rust-Joern raw source run across 1,000 C++ repositories

The frozen inventory contains 1,000 distinct repository names and 1,915
source file records and 1,909 distinct source hashes. The first 300
repository records are identical to the
earlier frozen inventory. The 700 additions contributed 1,337 files. Their
selection interleaved seven creation-date bands and fourteen repository
topics. All 21 search strata contributed additions. Repository topics help
vary the selection. They do not establish which features each source uses.
[Search queries](../manifests/github-cpp-1000-queries.json)

Each file has a pinned commit, Git blob hash, SHA-256 and byte length. The
collector inspected 1,014 repository records, including the 300 retained
records. Fourteen new candidates had no eligible source of the requested
kind and size. The primary selection favors implementation files and the
second selection adds a large file when available. That method can still
select tests, generated sources and copies of third-party code. GitHub
search and repository licensing metadata limit what the inventory covers.

The tests ran on macOS arm64 on the complete frozen inventory. The baseline
is the frozen Rust-Joern release executable used for the previous run. The
local probe has the qualified-template tokenization and C++ return-expression
boundary changes diagnosed on FlatBuffers and XGBoost. The raw experimental
population does not specify source platform, C++ standard, prerequisite
headers or build flags.

| Run | Files with function output | Files with no functions | Files rejected |
| --- | ---: | ---: | ---: |
| Baseline strict | 2 | 7 | 1,906 |
| Probe strict | 2 | 7 | 1,906 |
| Baseline permissive | 1,798 | 100 | 17 |
| Probe permissive | 1,799 | 99 | 17 |

The 17 permissive rejections came from non-UTF-8 input. The probe produced
function records in 987 repositories. Its permissive output changed on 15
files across 14 repositories, including one file that previously exported no
functions. Seven of the changed files are from the 700 additions. Exported
function counts rose on ten files and fell on none. The remaining five
changed serialized graph or diagnostic data without a count change.
Rust-Joern logged error diagnostics on 1,797 probe outputs. Both builds
completed the requested raw runs without a crash or timeout. The edge check
found zero references to absent CFG nodes. Function counts include
declarations, lambdas and any duplicate records.
Reliable function completeness and CFG correctness require an independent
source inventory with build context. The probe results remain diagnostic.

Clang 22.1.8 accepted 35 files across 29 repositories in a standalone GNU
C++17 check. Of 1,880 rejected files, 1,862 had a missing header or file
diagnostic. The baseline Rust-Joern strict pass on the 35 preprocessed files
yielded one output with functions, 13 with no functions and 21 rejections.
The compiler run uses the standalone profile and records no recovered project
build settings.

## Reproduction

Use the frozen manifest and its sibling `inputs/` directory to reproduce
the exact population. Re-running GitHub discovery can select later revisions.
The original local expansion command used the seed and the recorded queries.

```sh
python3 scripts/discover_github_cpp.py --seed /path/to/300/manifest.json \
  --query-file manifests/github-cpp-1000-queries.json --target 1000 \
  --output workspace/github-cpp-1000 --workers 10
python3 scripts/run_github_cpp.py --inventory /path/to/1000/manifest.json \
  --binary /path/to/rust-joern --output workspace/1000-permissive \
  --workers 3 --timeout 25 --permissive
```

Inputs, the frozen inventory, and individual graph records are stored under
the ignored `workspace/github-cpp-1000-2026-11-18/` directory. The summary
identifies the exact inventory and release binaries by hash.
